# RentVault Tenant App

The public-facing interface for RentVault, where tenants can browse rental listings and pay rent securely via escrow.

## 🎨 Design System
This app follows the RentVault "Funded Fintech" design language:
- **Typography**: Inter for body/headings, IBM Plex Mono for financial data.
- **Palette**: Emerald (Brand) and Nomba Yellow accents on a slate-scale foundation.
- **Motif**: Alternating light/dark sections with rounded-3xl cards and deep soft shadows.
