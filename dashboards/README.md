# RentVault Dashboards

The protected administration and management portal for RentVault, providing separate views for Landlords and System Administrators.

## 🎨 Design System
The dashboards are designed as a high-density operations console:
- **Theme**: Deep slate-950 sidebar for contrast, clean slate-50 main content area.
- **Typography**: Heavy-weight Inter headlines and IBM Plex Mono for transaction IDs and amounts.
- **Tokens**: Shares the central brand palette (Emerald/Nomba) with the public tenant site for a cohesive product experience.
